# 🚀 Formy

<div align="center">

### Build Beautiful Forms, Effortlessly.

A modern, responsive and intuitive drag-and-drop form builder inspired by Tally, built with **React, TypeScript, Tailwind CSS and Vite**.

---

</div>

##  Overview

Formy is a modern no-code form builder that allows users to create beautiful forms using an intuitive drag-and-drop interface.

It focuses on simplicity, performance and user experience while providing a clean editor, live preview and customizable form fields.

---

##  Features

- 🎨 Beautiful modern UI
- 🧩 Drag & Drop Form Builder
- 👀 Real-time Live Preview
- ⚡ Fast performance with Vite
- 📱 Fully Responsive Design
- 🎭 Smooth Framer Motion Animations
- 📝 Multiple Form Fields
- 🎯 Easy Property Editing
- 💾 Persistent State
- ♻️ Reusable Components
- 🌙 Clean & Minimal UX

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/paras84393/Formy.git
```

### Go to Project

```bash
cd Formy
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
